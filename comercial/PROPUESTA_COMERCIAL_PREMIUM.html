📊 Resumen Ejecutivo

NEXUS RIMEC es un ecosistema ERP completo desarrollado a medida para la gestión integral de comercio de calzados, desde la importación hasta la venta final, incluyendo e-commerce.

  • Multi-plataforma: Web + Desktop + Mobile responsive
