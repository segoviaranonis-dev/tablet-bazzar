Sección 03

Estructura Interna: Los 12 Módulos de NEXUS CORE

M01 // Sales Report

Análisis y Proyecciones de Venta

Filtros multidimensionales avanzados (vendedor, cliente, marca, periodos) con renders gráficos interactivos basados en Pandas y Plotly.

M02 // Carga Automatizada

Importación Masiva de Datos

Ingesta masiva a través de archivos Excel y CSV con validación estricta de esquemas estructurales antes de impactar en Supabase.

M03 // Motor de Precios

Estructuración de Descuentos en Cascada

Gobierna 4 listas activas (LPN, LPC02, LPC03, LPC04). Ejecuta fórmulas matemáticas en cascada: $Precio \times (1 - d_1/100) \times (1 - d_2/100)\dots$

M04 // Manejo de Casos

Matrices de Clasificación Marca × Caso

Clasificación dinámica de flujos de negocio (Ej: BR-VZ-MD-ML-MKA-O) mapeando origen, marca y tipo de cliente mayorista de forma automática.

M05 // Biblioteca de Precios

Repositorio y Versionado Histórico

Auditoría completa de variaciones en listas de costos. Permite simular el impacto en los márgenes de ganancia antes de su publicación.

M06 // Intención de Compra

Planificación de Pedidos de Importación

Registro y traza de necesidades de stock por marca mucho antes del envío de proformas oficiales por parte de las fábricas internacionales.

M07 // Digitación Inteligente

Carga Manual Guiada con Guardado en Base de Datos

Formularios optimizados con autocompletado inteligente y guardado persistente de borradores para la creación de registros sin pérdida de datos.

M08 // Pedido Proveedor

Gestor del Ciclo de Vida de Compras

Control total del estatus de órdenes internacionales (Borrador → Enviado → Confirmado → En Tránsito) indexando fechas estimadas de arribo (ETA).

M09 // Parser Proforma

Mapeo y Vinculación Automatizada con Markup

Algoritmo inteligente de lectura Excel para extraer curvas de calzado por color, calculando listas de venta sugeridas en base al markup configurado.

M10 // Stock en Tránsito

Estructuración y Control de la Vista `v_stock_rimec`

Cálculo dinámico de la disponibilidad real en la nube: $Disponibles = Total\,Proforma - Comprometido\,en\,Carritos$, evitando sobreventas.

M11 // Módulo Aprobación

Panel de Control para la Dirección General

Interfaz ejecutiva para autorizar o rechazar solicitudes de pedidos B2B, disparando de manera interna la reserva de stock a través de procedimientos PL/pgSQL.

M12 // Facturas Internas

División Automatizada Estricta Marca × Caso

Segmenta un pedido maestro en sub-comprobantes agrupados por marca y caso de negocio, asignando descuentos específicos a nivel de base de datos.

Sección 04

Canales Digitales: Módulos RIMEC WEB & BAZZAR WEB

RIMEC WEB (Fuerza Mayorista B2B)
W01 // Catálogo de Preventa

Renderizado veloz de productos indexados en stock virtual segregados por quincena de arribo.

W02 // Carrito Persistente

Sincronización en base de datos. Permite iniciar la venta en una PC de escritorio y cerrarla desde un celular en campo.

W03 // Metadata Cache

Uso de almacenamiento local para guardar estructuras estáticas, acelerando los tiempos de respuesta de la app.

W04 // Lógica de Fragmentación

Algoritmo en el frontend (Next.js) que desglosa visualmente el carrito según la combinación de Marca × Caso comercial.

W05 // Control de Doble Rol

Control de accesos estructurado para Vendedores y Administradores corporativos mediante validación JWT.

W06 // Bloqueo de Stock Temporal

Token de seguridad de 60 segundos que asegura el inventario durante el paso crítico de validación y confirmación.

W07 // Middleware Perimetral

Capa de control en Vercel que bloquea de forma inmediata ataques comunes y escaneos de vulnerabilidades.

W08 // Resguardos Automatizados

Scripts diarios (GitHub Actions) que extraen copias comprimidas de la base de datos hacia repositorios aislados.

BAZZAR WEB (Canal Minorista B2C - En Desarrollo)
B01 // Portal Público B2C

Catálogo directo al consumidor final, conectado de manera exclusiva con los remanentes de stock real en depósito físico.

B02 // Depósito Web Sincronizado

Gestión de stock físico disponible una vez que los contenedores llegan al depósito general de la distribuidora.

Sección 05

El Ciclo Operativo del Negocio: Flujo de Fin a Fin

1

Importación e Ingesta Planificada

Se procesa la proforma en formato Excel a través de Nexus Core, el sistema calcula de forma instantánea las cuatro listas de precio con su respectivo markup y da de alta los productos en la vista global v_stock_rimec como Stock en Tránsito.

2

Preventa Transaccional Mayorista B2B

Los vendedores levantan los pedidos de los clientes desde RIMEC WEB consumiendo el stock virtual en tránsito. El sistema bloquea el inventario por 60 segundos bajo un token único para validar precios netos y confirmar la orden de compra.

3

Auditoría, Fragmentación y Autorización Gerencial

La Dirección General evalúa la solicitud desde el panel de aprobación. Al dar clic en aprobar, el backend ejecuta procedimientos PL/pgSQL que dividen la orden en Facturas Internas estructuradas estrictamente bajo la combinación de Marca × Caso.

4

Arribo y Conversión Física en Depósito

Una vez que la mercadería llega físicamente al país, el stock se traslada de forma automática de la categoría de Tránsito hacia Stock Real en Depósito, dejando las órdenes listas para el empaque y despacho logístico final.

5

Monetización del Remanente en Canal Minorista B2C

Los pares sobrantes que no se vendieron en el canal mayorista se publican automáticamente en el portal público BAZZAR WEB para su venta unitaria directa al consumidor final, maximizando el margen de ganancia líquida.
