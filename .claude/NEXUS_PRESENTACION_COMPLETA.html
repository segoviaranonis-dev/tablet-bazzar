Flujo Paralelo: Motor de Precios genera artículos con precio que se unen a Pedido Proveedor

📊 Informe de Ventas
Análisis multidimensional: Cliente, Marca, Vendedor + Generación PDF en lote

🎯 Análisis Multidimensional

  • Por Cliente: Historial completo de compras, productos favoritos, frecuencia
  • Por Marca: Rendimiento de cada marca, participación en ventas
  • Por Vendedor: Performance individual, cumplimiento de metas, comisiones

📄 Generación de PDF en Lote

Sistema genera reportes masivos automáticamente para distribución a vendedores, gerencia y stakeholders.

  • PDFs personalizados por vendedor con su performance
  • Reportes ejecutivos para gerencia
  • Análisis de tendencias por marca
  • Exportación programada (diaria, semanal, mensual)
💡 Integración 5 Pilares Todos los reportes respetan la filosofía de los 5 Pilares RIMEC para trazabilidad completa.
📝 Intención de Pedidos
Registro de Intención: Compra Previa o Programada

📋 Tipos de Intención

  • Compra Previa: Cliente expresa interés en productos antes de pedido formal
  • Compra Programada: Pedidos planificados con anticipación (calendario)
  • Registro de Intención: Captura de necesidades del cliente para análisis

🎯 Objetivo

Capturar la intención de compra antes de que se convierta en pedido formal. Esto permite:

  • Planificar inventario con anticipación
  • Negociar mejores condiciones con proveedores
  • Reducir tiempos de entrega
  • Maximizar conversión de intención a venta
✅ Primera Fase del Proceso La Intención es la ENTRADA del sistema. De aquí se pasa a Digitación para formalizar el pedido.
⌨️ Digitación y Distribución
Procesamiento formal de pedidos y asignación a proveedores

⌨️ Digitación

Conversión de la Intención en un Pedido Formal en el sistema.

  • Ingreso formal de productos, cantidades y condiciones
  • Validación contra stock disponible
  • Cálculo de precios según caso activo
  • Generación de ID único de pedido

📦 Distribución

Asignación del pedido a proveedores según disponibilidad y condiciones.

  • Selección de proveedor óptimo (precio, plazo, stock)
  • División de pedido si requiere múltiples proveedores
  • Creación de órdenes de compra (OC)
  • Notificación automática a proveedores
⚡ Punto Crítico Aquí se decide QUÉ comprar y a QUIÉN. Una buena distribución optimiza costos y tiempos.
📦 Pedido Proveedor
Gestión de Órdenes de Compra + Facturas Internas

📦 Gestión de Pedidos

  • Generación de OC: Orden de compra formal al proveedor
  • Seguimiento de Estado: Pendiente → Confirmado → En Tránsito → Arribado
  • Facturas Internas: Ejecución de facturas dentro del módulo
  • Cierre al Arribo: Pedido se cierra cuando mercadería llega
🔗 PUNTO DE CONEXIÓN CRÍTICO De PEDIDO PROVEEDOR sale RIMEC WEB (catálogo con artículos disponibles para vendedores)

💖 Unión con Motor de Precios

El Motor de Precios (flujo paralelo) genera artículos con precio que se unen aquí:

  • Evento (Listado Precio) del motor se asocia a productos del Pedido Proveedor
  • Artículos obtienen precio automáticamente según caso
  • Sistema valida que artículo tenga precio antes de aparecer en RIMEC Web
✅ Cierre Automático Cuando mercadería arriba, Pedido Proveedor se cierra y pasa automáticamente a COMPRAS.
🛒 RIMEC Web
Catálogo para Vendedores - Sale de Pedido Proveedor
🔗 Origen RIMEC Web NO es un módulo independiente. SALE de PEDIDO PROVEEDOR con artículos que ya tienen precio del Motor.

🛒 Funcionalidades

  • Catálogo de Productos: Solo artículos con precio y stock disponible
  • Carrito de Compras: Vendedor arma pedido para cliente
  • Motor de Precios Dinámico: Precios según caso activo
  • Confirmación de Pedido: Genera preventa con número único
  • Mis Preventas: Vendedor ve historial de pedidos

💰 Precio Automático

Los precios vienen del Motor de Precios:

  • Artículo tiene asociado un EVENTO (Listado de Precio)
  • EVENTO tiene un CASO (estrategia comercial)
  • Precio se calcula automáticamente según caso
  • Vendedor VE el precio final, NO lo modifica
⚡ Preventas van a Aprobación Cada pedido confirmado en RIMEC Web genera una preventa que debe ser aprobada en el módulo siguiente.
✅ Aprobación de Pedidos RIMEC Web
Validación de Preventas con Número Único para Máximo Monitoreo

✅ Proceso de Aprobación

  • Revisión: Gerencia revisa pedidos ingresados en RIMEC Web
  • Validación Comercial: Verifica condiciones, precios, disponibilidad
  • Aprobación/Rechazo: Decisión final sobre el pedido
  • Notificación: Vendedor recibe confirmación o rechazo
🔢 Preventas con Número Único Cada preventa recibe un ID único e irrepetible para trazabilidad máxima. Esto permite monitoreo completo del pedido desde intención hasta entrega.

📊 Trazabilidad Completa

Con el número único de preventa se puede rastrear:

  • Quién creó el pedido (vendedor)
  • Cuándo se creó (timestamp)
  • Qué productos y cantidades
  • Qué caso de precio se aplicó
  • Quién aprobó/rechazó
  • Estado actual del pedido
✅ Pedidos Aprobados → Compras Una vez aprobados, los pedidos pasan al módulo de COMPRAS para gestión de mercadería.
🚚 Módulo de Compras
Recepción de Mercadería - Conectado a Pedido Proveedor
🔗 Conexión con Pedido Proveedor Cuando mercadería arriba, Pedido Proveedor se CIERRA automáticamente y pasa a COMPRAS.

🚚 Recepción de Mercadería

  • Registro de Arribo: Mercadería llega y se registra en sistema
  • Verificación: Se valida contra Pedido Proveedor (cantidades, productos)
  • Control de Calidad: Inspección física de mercadería
  • Baja de Mercadería: Se da de baja en el módulo

👤 Autorización Usuario

Usuario con rol adecuado autoriza la mercadería recibida y decide destino:

  • Opción 1: Enviar a FACTURACIÓN (para documentar)
  • Opción 2: Enviar a DEPÓSITO (almacenamiento directo)
⚡ Decisión Crítica La decisión Facturación vs Depósito determina el siguiente paso del flujo.
📄 Facturación / Depósito
Documentación O Almacenamiento - Detección Cliente 5000

📄 Facturación

Generación de documentos fiscales para la mercadería recibida.

  • Creación de facturas
  • Asociación con Pedido Proveedor
  • Registro contable
  • Documentación completa
🤖 DETECCIÓN AUTOMÁTICA CLIENTE 5000 Si el cliente asociado a la mercadería es el Cliente 5000 (BAZZAR), el sistema detecta automáticamente y ejecuta transferencia sin intervención humana.

🔄 Transferencia Automática BAZZAR

Cuando Cliente = 5000:

  • Detección: Sistema identifica Cliente 5000
  • Transferencia: Mercadería pasa automáticamente a BAZZAR Web
  • Sin Intervención Humana: Proceso 100% automatizado
  • Trazabilidad: Registro completo del movimiento
✅ Siguiente Paso Mercadería transferida a BAZZAR Web → Depósito BAZZAR → Precio Automático
🔄 BAZZAR Web - Transferencia Automática
Cliente 5000 → Depósito → Precio Automático SIN Humano
🤖 100% AUTOMATIZACIÓN Todo este proceso ocurre SIN intervención humana. Sistema detecta, transfiere, deposita y marca precio automáticamente.

1️⃣ Recepción en BAZZAR Web

  • Mercadería llega desde Facturación (Cliente 5000)
  • Sistema registra ingreso automático
  • Validación contra 5 Pilares
  • Asociación con caso de precio

2️⃣ Asignación a Depósito

  • Mercadería pasa a uno de los 6 depósitos BAZZAR
  • Asignación según reglas (cercanía, stock, rotación)
  • Actualización de inventario en tiempo real
  • Disponible para venta en Tablet BAZZAR

3️⃣ Precio Automático según Caso

SIN intervención humana, el sistema:

  • Consulta qué CASO acompaña al artículo
  • Aplica precio del EVENTO activo
  • Marca precio de venta automáticamente
  • Artículo listo para vender en BAZZAR
🌿 Fase 1 Hiedra Venenosa Esta automatización es parte de la estrategia de infiltración. BAZZAR empieza a depender del sistema RIMEC sin saberlo.
💖 CORAZÓN 1: Biblioteca de Casos
Cerebro Comercial - Define Estrategias
💖 PRIMER CORAZÓN La Biblioteca de Casos es el CEREBRO comercial. Aquí se definen las estrategias y análisis comerciales.

🎯 ¿Qué Contiene?

  • CASOS: Estrategias comerciales definidas (Liquidación, Premium, Mayorista, etc.)
  • Análisis: Efectividad de cada estrategia
  • Reglas de Negocio: Condiciones y restricciones
  • Historial: Casos pasados para aprender

🧠 Por Qué es el "Cerebro"

De aquí vienen:

  • Estrategias de pricing dinámico
  • Análisis de estrategias comerciales
  • Decisiones de negocio basadas en datos
  • Optimización de márgenes
➡️ Siguiente Paso Un CASO de la biblioteca se combina con EXCEL en el Importador para generar EVENTO (Corazón 2).
📊 Importador de Precios
Procesa Excel con Productos y Márgenes

📊 Función

Lee archivos Excel con productos, valida contra 5 Pilares y prepara para generar evento.

  • Lee Excel con códigos de producto, descripciones, precios base
  • Valida que cada producto tenga: Línea, Referencia, Material, Color, Talla
  • Procesa márgenes y condiciones especiales
  • Prepara datos para combinarse con CASO
⚡ Validación 5 Pilares Si un producto NO tiene los 5 Pilares completos, el importador lo rechaza. Esto garantiza trazabilidad molecular.

🔄 Proceso

  • Paso 1: Usuario sube Excel
  • Paso 2: Sistema valida formato y 5 Pilares
  • Paso 3: Se combina con CASO seleccionado
  • Paso 4: Genera EVENTO (Corazón 2)
💖 CORAZÓN 2: EVENTO = Caso + Excel
Listado de Precio - Músculo Ejecutor
💖 SEGUNDO CORAZÓN CASO (Biblioteca) + EXCEL (Productos) = EVENTO (Listado de Precio con todos los SKUs y precios calculados)

🧮 La Fórmula

Caso + Excel = EVENTO (Listado de Precio)

📋 ¿Qué Contiene un EVENTO?

  • SKUs con Precio: Todos los productos con precio calculado
  • Vigencia: Fecha inicio y fin
  • Condiciones: Tipo de cliente, canal, volumen
  • Caso Asociado: Referencia al caso que lo generó
➡️ Siguiente Paso EVENTO se combina con PROFORMA para crear artículo disponible para venta.
📄 Proforma
Formato de Presentación del Artículo

📄 ¿Qué es una Proforma?

Es el formato de presentación de cómo se muestra el artículo al vendedor/cliente.

  • Define cómo se visualiza el producto
  • Incluye imágenes, descripciones, especificaciones
  • Formato de precio (con/sin IVA, descuentos visibles, etc.)
  • Información adicional (stock, plazo entrega, etc.)

🔗 Unión con Evento

EVENTO + PROFORMA = Artículo Disponible para Venta

  • Evento aporta: Precio calculado, vigencia, condiciones
  • Proforma aporta: Presentación visual, formato
  • Resultado: Artículo completo listo para RIMEC Web
➡️ Destino Final El artículo resultante se conecta a PEDIDO PROVEEDOR y aparece disponible en RIMEC Web para vendedores.
🚀 Artículo Disponible para Venta
Evento + Proforma = Listo para RIMEC Web
✅ RESULTADO FINAL DEL MOTOR DE PRECIOS Artículo completo con precio, formato y listo para que vendedores lo ofrezcan en RIMEC Web.

🚀 Características del Artículo

  • Precio Calculado: Según caso del Motor de Precios
  • Trazabilidad Completa: 5 Pilares RIMEC validados
  • Formato Profesional: Presentación según Proforma
  • Vigencia Activa: Solo disponible si evento está vigente
  • Stock Validado: Asociado a Pedido Proveedor

🔗 Conexión a Pedido Proveedor

Este artículo se une a PEDIDO PROVEEDOR (flujo principal):

  • Artículo con precio se asocia a mercadería del pedido
  • Sistema valida que haya stock físico
  • Aparece en RIMEC Web para vendedores
  • Vendedor puede crear preventa
💖 Aquí se unen LOS DOS CORAZONES El trabajo del Motor de Precios (Biblioteca + Importador + Evento + Proforma) culmina aquí y se conecta al flujo principal de Control Central.
