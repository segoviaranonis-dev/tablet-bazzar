💖 CORAZÓN 1 del Sistema La Biblioteca de Casos es el CEREBRO comercial de todo NEXUS CORE. Sin esto, el motor de precios no funciona. Define CÓMO se vende.

🎯 ¿Qué es un CASO?

Un CASO es una estrategia comercial definida con reglas de negocio específicas.

Cada caso contiene:

  • Nombre: Identificador único (ej: "Liquidación Verano 2026")
  • Tipo de Estrategia: Descuento, Premium, Mayorista, Promoción, etc.
  • Reglas de Negocio: Porcentaje descuento, margen mínimo, condiciones
  • Vigencia: Fecha inicio y fin del caso
  • Condiciones de Aplicación: Tipo cliente, volumen, canal, etc.

🧠 Por qué es el "Cerebro"

La Biblioteca de Casos es donde se definen las estrategias comerciales y se realiza el análisis de negocio.

De aquí surgen:

  • Estrategias de pricing dinámico
  • Análisis de efectividad de casos pasados
  • Decisiones comerciales basadas en datos
  • Optimización de márgenes por segmento

📋 Tipos de Casos Disponibles

🔥 Liquidación

Descuentos agresivos para rotar stock de temporada

⭐ Premium

Márgenes altos para productos exclusivos

📦 Mayorista

Descuentos por volumen para distribuidores

🎯 Promoción

Ofertas especiales por fecha (Black Friday, etc.)

🆕 Lanzamiento

Precios introductorios para nuevos productos

🔁 Recurrente

Precios especiales para clientes frecuentes

💡 Casos Combinables Un mismo artículo puede estar en múltiples casos simultáneamente. El sistema aplica la mejor opción para el cliente automáticamente.

Nombre: "Liquidación Verano 2026"
Tipo: Liquidación por Temporada
Descuento: 30% sobre precio base
Vigencia: 2026-03-01 a 2026-03-31
Condiciones: Todos los clientes
Productos: Línea Verano (500 SKUs)
Margen Mínimo: 15%
Canal: RIMEC Web + Tablet BAZZAR

📊 Análisis de Estrategias Comerciales

La Biblioteca de Casos permite analizar la efectividad de cada estrategia:

  • Comparación de Casos: ¿Qué estrategia vendió más?
  • ROI por Caso: ¿Cuál generó mayor margen?
  • Rotación de Stock: ¿Cuál ayudó a liquidar inventario?
  • Análisis Temporal: ¿Cuándo funcionan mejor ciertas estrategias?
  • Segmentación: ¿Qué estrategia prefiere cada tipo de cliente?

💖 CORAZÓN 2 del Sistema La combinación de un CASO con un archivo EXCEL genera un EVENTO (Listado de Precio). Es el músculo que ejecuta las estrategias del Corazón 1.

🧮 La Fórmula Fundamental

Caso (Biblioteca) + Excel (Productos/Márgenes) = EVENTO (Listado de Precio)

CASO: Define la estrategia (¿CÓMO vender?)
EXCEL: Contiene productos y condiciones (¿QUÉ vender?)
EVENTO: Resultado con precios calculados (LISTO para vender)

⚠️ Regla Crítica Un CASO solo NO genera precios. Un EXCEL solo NO tiene estrategia. Ambos juntos crean un EVENTO funcional.

🔄 Proceso de Generación de Evento

1
Seleccionar Caso
Usuario elige un caso de la Biblioteca (ej: "Liquidación Verano 2026")
↓
2
Cargar Excel
Excel contiene: Código producto, Descripción, Precio base, Margen deseado
↓
3
Validación 5 Pilares
Sistema valida que cada producto tenga: Línea, Referencia, Material, Color, Talla
↓
4
Cálculo de Precios
Importador aplica reglas del CASO a cada producto del EXCEL
↓
5
Generación EVENTO
Sistema crea EVENTO con 500 SKUs + precios + vigencia + condiciones
↓
6
Almacenamiento
EVENTO se guarda en base de datos, listo para unir con Proforma
✅ Sin Intervención Humana Todo el proceso es automático. Usuario solo sube Excel, sistema hace el resto.

🔗 Siguiente Paso: Unión con Proforma

Una vez generado el EVENTO, se une con una PROFORMA (formato de presentación) para crear el artículo final disponible en RIMEC Web.

Evento + Proforma = Artículo Disponible para Venta
