## 1 · Regla de oro — cada doc que entra a `moria_chusar`

A partir de 2026-08-07, **toda** documentación que se cargue / sincronice a `moria_chusar` (sobre todo `content/claude/` y el puente) debe poder responder, en lenguaje **claro**:

| Pregunta | Obligatorio en el doc o en el CHANGELOG del lote |
|----------|--------------------------------------------------|
| ¿Qué cambió? | Sí |
| ¿Por qué? | Sí (una frase) |
| ¿Qué debe hacer Andrés / su Cursor? | Sí · o “nada — solo leer” |
| ¿Qué queda **igual** (inmutable)? | Sí |
| ¿Hay que tocar Git / DB / WhatsApp? | Sí · explícito · si no → “no” |
| ¿Cómo lo haría alguien sin saber programar? | Pasos numerados o “solo pasale este texto a Cursor” |

**Prohibido** en docs para este canal: solo jerga, solo rutas sin explicación, asumir que “ya saben”.

**Zip:** lo arma **Héctor** cuando quiera — el agente **no** debe insistir en comprimir.
