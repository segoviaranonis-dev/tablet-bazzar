# 4.01.04.001 — RIMEC Web · precios visibles sin activar venta

**Severidad:** 🟡 MEDIA → corregida UI (reapertura confecciones 2026-07-17)  
**App:** rimec-web · `:3001` · prod  
**Estado:** ✅ **RESUELTO UI 2026-07-17** (calzado 2026-07-15 + confecciones 2026-07-17)  
**Detectado:** 2026-07-14 · **Reabrió:** 2026-07-15 (acordeón) · **Reabrió confecciones:** 2026-07-17

## Síntoma

Precios **Gs.** visibles en catálogo **sin** Activar venta:

1. **2026-07-14:** lightbox modal (`Precio Gs.`).
2. **2026-07-15:** acordeón por lote (bajo badge «N p») + panel expandido («Gs. … / par»).
3. **2026-07-17:** **confecciones** — etiqueta naranja `formatPrecioGs` sobre grupos de tallas (`CatalogConfeccionesTallas`) aunque el botón diga «Activar venta para cargar».

## Causa

| Fecha | Causa |
|-------|-------|
| 2026-07-15 | `CatalogLotesAcordeon` / `CatalogPanelOrigen` sin guard `activa` |
| 2026-07-17 | Fix calzado **no** cubría confecciones: precio siempre renderizado en banda por precio |

## Fix

| Fecha | Archivo | Cambio |
|-------|---------|--------|
| 2026-07-15 | `CatalogLotesAcordeon` · `CatalogPanelOrigen` · `CatalogoGrid` | precio solo si `activa` |
| 2026-07-17 | `CatalogConfeccionesTallas.tsx` | `formatPrecioGs` solo si `activa`; sin sesión una sola banda de tallas (sin tipificar Gs.) |

## Protocolo producto

| Sesión | Badge pares / tallas | Precio | Lightbox | + carrito |
|--------|----------------------|--------|----------|-----------|
| No activa | Visible | **Oculto** | **Oculto** | Bloqueado (Activar venta) |
| Activa + cliente + lista | Visible | Visible si hay LPN/tier | Visible | Habilitado |

## Vector residual (no cerrado)

API `/api/catalogo/tarjetas` sigue enviando `lpn`/`lpc*` en JSON (DevTools). Mitigación opcional futura: omitir columnas precio sin cookie de sesión de venta.
