### **SQL generado (catalogo-sql.ts):**
```sql
SELECT
  s.linea_id,
  s.referencia_id,
  -- ... otros campos ...
FROM public.deposito_tienda_fernando_adultos s
  LEFT JOIN public.material mat ON mat.id = s.material_id
  LEFT JOIN public.color col ON col.id = s.color_id
  LEFT JOIN public.marca_v2 mv ON mv.id_marca = s.marca_id
  LEFT JOIN public.genero g ON g.id = s.genero_id
  LEFT JOIN public.grupo_estilo_v2 ge ON ge.id_grupo_estilo = s.grupo_estilo_id
  LEFT JOIN public.tipo_v2 tv ON tv.id_tipo = s.tipo_v2_id  -- ❌ POSIBLE PROBLEMA
```

### **Hipótesis de fallo:**

**Opción A: Tabla `tipo_v2` no existe**
- Query hace JOIN con `public.tipo_v2`
- Tabla puede no existir en Supabase

**Opción B: Columna `tipo_v2_id` no existe**
- SELECT usa `s.tipo_v2_id`
- Columna puede no existir en `deposito_tienda_*`

**Opción C: Nombre de columna incorrecto**
- Puede ser `tipo_id` en lugar de `tipo_v2_id`
- Puede ser `tipo_calzado_id` u otro nombre

## 🛠️ SOLUCIÓN PROPUESTA

### **Paso 1: Verificar esquema BD**

Ejecutar en Supabase:
```sql
-- Ver columnas de deposito
SELECT column_name, data_type 
FROM information_schema.columns 
WHERE table_name = 'deposito_tienda_fernando_adultos'
  AND column_name LIKE '%tipo%';

-- Ver si existe tabla tipo_v2
SELECT tablename 
FROM pg_tables 
WHERE tablename LIKE '%tipo%';
```

### **Paso 2: Hotfix temporal**

Si la tabla/columna no existe, comentar o manejar con COALESCE NULL:

```typescript
// En lib/server/catalogo-sql.ts línea 86
// Cambiar:
LEFT JOIN public.tipo_v2 tv ON tv.id_tipo = s.tipo_v2_id

// Por (temporal):
LEFT JOIN public.tipo_v2 tv ON tv.id_tipo = s.tipo_v2_id
  OR tv.id_tipo IS NULL  -- Permitir NULL sin error
```

O eliminar completamente tipo_v2 si no se usa:
```typescript
// Comentar línea 71 y línea 86
// COALESCE(NULLIF(btrim(tv.descp_tipo::text), ''), '(sin tipo)') AS tipo_v2,
'(sin tipo)' AS tipo_v2,  -- Hardcoded temporal
```

### **Paso 3: Fix definitivo**

Una vez verificado el esquema real:
1. Ajustar nombre de tabla/columna correcto
2. O crear tabla tipo_v2 si debería existir
3. O remover funcionalidad tipo si no aplica a Tablet
