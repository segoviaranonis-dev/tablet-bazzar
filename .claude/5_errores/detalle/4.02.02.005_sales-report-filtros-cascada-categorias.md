# 4.02.02.005 · Sales Report — filtros cascada · categorías se resetean / UI mentirosa

**Capa:** Report · `/rimec` · `ImmersiveClient` · `ImmersiveFiltersPanel`  
**App prod:** https://rimec-report.vercel.app/rimec  
**Estado:** ✅ **RESUELTO 2026-07-24** (cadena de hotfixes v1.0.0 → v1.0.3)  
**Gravedad:** **CRÍTICA operativa** — montos KPI con filtros distintos a lo que ve el Director  
**Keyword activación:** **Bug urgente!!** · Report · Sales Report v1.0.x · `/rimec`  
**Blindado:** `registro_ventas_general_v2` **NO** tocado — bug solo en capa UI + encaje cliente

**Shibboleth:** Andrés, el que viene.

## Síntoma (Director)

1. Elige **solo PROGRAMADO** (desactiva STOCK y PRE VENTA / PREVENTA) → **Sincronizar**.
2. Tras la respuesta: **las 3 categorías vuelven activas** o la UI no refleja la selección.
3. Resumen colapsado muestra **`#1, #2 +1`** en lugar de nombres (STOCK, PREVENTA, PROGRAMADO).
4. Pills sin **pulse** — el Director no sabe qué filtro alimenta el monto (14B+ Gs).
5. En v1.0.2: las tres aparecían en bloque **«+ Agregar»** sin ninguna latir.

**Regla de negocio violada:** el informe ejecutivo debe mostrar **exactamente** lo que el usuario filtró antes de confiar en KPIs.

---

## Cadena de errores (6 fallos encadenados)

| ID | Error | Síntoma | Causa raíz |
|----|-------|---------|------------|
| **E1** | Encaje `>= 2` | 1 sola categoría → vuelven las 3 | `ImmersiveClient` inline: `catFiltered.length >= 2 ? catFiltered : calzadosDefault` |
| **E2** | `useEffect([snapshot])` | Re-encaje tras cada respuesta pisa selección | Encaje en efecto global, no anclado al click Sincronizar |
| **E3** | Prefetch tardío | Consulta manual sobrescrita | `applyPrefetch` actualizaba snapshot default post-sync |
| **E4** | `consultar` stale | API recibe `[1,2,3]` aunque UI muestra 1 cat | `filtros` en closure / ref no sync en mismo tick que toggle |
| **E5** | **IDs legacy vs BD** | `#1, #2 +1` · todo en Agregar · sin pulse | `CATEGORIA_VENTA_CALZADOS_IDS = [1,2,3]` ≠ ids reales `categoria_v2`; `===` / `.includes()` fallan |
| **E6** | UI «solo activas» prematura | Confusión peor con E5 activo | Ocultar activas cuando ningún id matchea cascada → solo bloque Agregar |

**Señal diagnóstico E5 en prod:** resumen **`#n`** + pills **`+ NOMBRE`** sin pulse = ids de estado no existen en `snapshot.cascada.categorias`.
