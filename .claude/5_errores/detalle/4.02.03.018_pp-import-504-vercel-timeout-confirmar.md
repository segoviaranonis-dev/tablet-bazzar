## Causa raíz

Al confirmar (`phase=ppd`), el motor **repetía** trabajo ya hecho en preview paso 1:

1. `previewImportProformaProgramadoTs` completo (auditoría pilares×precio + reporte biblioteca).
2. `provisionPilaresFromProforma` **dentro** de transacción PPD (cientos de queries serializadas).
3. Post-import: segunda auditoría + `buildProformaPilaresImportReport`.

Proformas medianas/grandes superaban el techo serverless → **504**.

---

## Fix (2026-07-23)

| Pieza | Cambio |
|-------|--------|
| `gateProgramadoPpdFast` | Paso 2: solo ICs + listado + totales — **sin re-preview** |
| `preparePpdImportLookups` | Pilares **fuera** de `BEGIN`/`COMMIT` |
| `phase=ppd` return | Sin post-audit duplicado (avisos en preview) |
| `proforma-pilares-provision.ts` | Menos queries tono por color |
| `vercel.json` | Wildcard `maxDuration: 300` rutas PP |
| `PpTabStock.tsx` | Mensaje 504 + recargar PP |
