# 4.02.03.004 · «Dato duro» expuesto en UI Stock Tránsito

**Capa:** Report · `/stock-transito`  
**Estado:** ✅ Corregido 2026-07-05  
**Gravedad:** UX / nomenclatura — confusión Director  
**Keyword origen:** Director · **Documenta**

## Síntoma

Fila de filtros mostraba etiqueta **«Dato duro»** con chips grandes de quincena — lenguaje de documentación interna, no de operador.

## Causa

«Dato duro» en Moria = referencia conceptual a `quincena_arribo_id` (FK estable vs ETA), **igual que «Alejandro Magno»** nombra una etapa — **no** es copy de pantalla. Se filtró al UI por error de implementación.

## Fix UI

- Etiqueta usuario: **Llegada**
- Control: dropdown **multi-select** minimalista (paridad `rimec-web` · `DropdownFilterQuincena`)
- Componente: `FiltroLlegadaMulti.tsx`
- Estado: `quincenaIds: string[]` (antes single `quincenaId`)

## Doc

- `CHUSAR_STOCK_TRANSITO_ESTRATEGIA_VENTAS.md` § etiqueta UI
- Memoria técnica sigue diciendo «dato duro» solo en contexto FK/BD
