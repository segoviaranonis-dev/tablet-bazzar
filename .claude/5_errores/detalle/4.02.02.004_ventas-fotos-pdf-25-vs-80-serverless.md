# 4.02.02.004 · Ventas + Fotos PDF — serverless 25 filas vs banner 80

**Capa:** Report · `/ventas-fotos` · API PDF Vercel  
**Estado:** ✅ **RESUELTO 2026-07-10**  
**Gravedad:** Operativa — entregable comercial incompleto  
**Keyword cierre:** Director · hotfix · **Documentación Chusar**

---

## Síntoma

PDF descargado desde prod (`ventas-fotos-104-VIZZANO-2025-10-01-2025-10-31.pdf`):

- Primera página: aviso «primeras **80** filas».
- Detalle: **~25 filas** y corte abrupto.

---

## Causa

`pdfGenerator.ts` — rama serverless:

```typescript
// Antes (bug):
const recommendedLimit = isServerless ? 25 : getRecommendedImageLimit(deviceType)
const MAX_FILAS_PDF = isServerless
  ? Math.min(recommendedLimit, 25)
  : data.rows.length
```

Banner hardcodeado «80» desincronizado del slice real.
