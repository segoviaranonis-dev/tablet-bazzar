**Código:** `4.02.03.013`  
**App:** Report · `rimec-report.vercel.app`

**Estado:** ✅ **RESUELTO** · commit report `7b7d5d7`

---

## Síntoma

Botón **Descargar PDF** en `PpFiCard` → toast rojo **«No se pudo generar el PDF»**.

---

## Causa

API ejecutaba `runFiPdfPython` → `control_central/generar_pdf_cli.py`. **Vercel no tiene Python ni `control_central`** → HTTP 500 JSON → cliente muestra error genérico.

---

## Fix

| Archivo | Rol |
|---------|-----|
| `run-fi-pdf.ts` | Orquestador: Node primero · Python fallback local |
| `fi-pdf-data.ts` | Query FI + PPD desde Postgres |
| `fi-pdf-generator.ts` | pdf-lib (paridad `rimec-web/lib/pdfGenerator.ts`) |
| `lib/pdf/pdfImageUtils.ts` | Imágenes Supabase con retry |

Smoke: `tsx scripts/smoke_fi_pdf.ts 80` → ~100 KB.

---

## Lección (ineficiencia)

Documentar en CHUSAR «PDF solo local» **no basta** — cualquier botón en prod debe tener **ruta serverless** o deshabilitarse con mensaje explícito.
