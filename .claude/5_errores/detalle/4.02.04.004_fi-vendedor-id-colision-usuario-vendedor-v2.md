# 4.02.04.004 · Facturación — colisión `fi.vendedor_id` usuario ↔ `vendedor_v2`

**Código:** `4.02.04.004`  
**App:** Report · Facturación PE / tránsito / bóveda · Aprobaciones · CSV / PDF FI  
**Detectado:** 2026-08-03 · Boutique Carmen · PE-245 · UI mostraba **Guido**  
**Estado:** ✅ **RESUELTO** UI (helper display) + sellado confirmar Web · datos PE-245 realineados a usuario **41**  
**CHUSAR:** `2.3.1.9.F` · `CHUSAR_TRADUCTOR_VENDEDOR_CARLOS_PE.md` § Colisión id 19

---

## Síntoma

En bandejas de facturación (y FI relacionadas) el vendedor aparece como **Guido** cuando la venta es de **PATRICIA** (u otro vendedor Web).

Caso índice: pedido **245** · cliente BOUTIQUE CARMEN · FI PE-245-001 / PE-245-002.

---

## Causa

| Tabla | id **19** |
|-------|-----------|
| `usuario_v2` | **Guido** (DIOS) |
| `vendedor_v2` | **PATRICIA** |

Ley PE/Web: `factura_interna.vendedor_id` = **`usuario_v2.id_usuario`** (Patricia = **41**).

Un “fix” o JOIN a `vendedor_v2` por el mismo número escribe/lee **19** como si fuera el catálogo de vendedores → la UI que hace `JOIN usuario_v2` muestra **Guido**.

Casi todos los ids 1–22 colisionan entre las dos tablas (personas distintas).

---

## Fix

1. **Helper canónico** `report/src/lib/facturacion/vendedor-fi-display.ts`  
   Display: `payload.vendedor_nombre` → `usuario_v2` → `vendedor_v2`.
2. **Aplicado en:** bandeja PE · tránsito · bóveda · Aprobaciones FI · CSV PE · CSV general · CSV/PDF PP · Logística OK (rama FI).
3. **Confirmar carrito** (`rimec-web`): RPC siempre con `session.id_usuario`; sella `payload.vendedor_id` / `vendedor_nombre` con la sesión.
4. **Datos:** PE-245 restaurado a `vendedor_id = 41`.

---

## Prevención (ley)

- **Prohibido** asignar `vendedor_v2.id` a `fi.vendedor_id` en flujos Web/PE.
- **Prohibido** mostrar vendedor solo con `JOIN vendedor_v2 ON id = fi.vendedor_id` sin payload/usuario primero.
- Scripts de “alineación” deben resolver por **nombre** (`payload` / `descp_usuario`), nunca asumir que el mismo entero es la misma persona.
- Campo de sesión Web `id_vendedor` en carrito = **id_usuario** (nombre legado) — ver `DialogoActivacion` / `SesionSyncProvider`.
