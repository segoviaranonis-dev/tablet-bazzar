# 4.02.01.002 · Report — Crear biblioteca · POST ausente · JSON vacío

**Capa:** Report · Motor de precios · API `/api/motor-precios/biblioteca`  
**App:** https://rimec-report.vercel.app  
**Ruta UI:** `/proceso-importacion/motor-precios/biblioteca/nueva`  
**Estado:** ✅ **RESUELTO** 2026-07-02  
**Keyword origen:** hotfix operativo (funcionarios bloqueados en prod)

---

## Síntoma

Al pulsar **Crear biblioteca** (logueado como RIMEC Admin):

```
Failed to execute 'json' on 'Response': Unexpected end of JSON input
```

Prod reproducía el fallo; local podía funcionar si el código tenía el handler POST sin deploy.

---

## Causa raíz

1. **API incompleta:** `route.ts` de biblioteca exportaba solo **GET**. El UI hacía **POST** → Next devolvía **405** con cuerpo vacío → `response.json()` explotaba.
2. **Deploy desacoplado:** el fix commiteado (`7afb506`) no llegó a **rimec-report** (git push no disparó build; un deploy CLI previo fue al proyecto **`report`** / `report-plum-one.vercel.app`, no al alias de funcionarios). Ver **4.02.02.003**.

---

## Fix

| Archivo | Cambio |
|---------|--------|
| `report/src/app/api/motor-precios/biblioteca/route.ts` | Handler **POST** + validación JSON |
| `report/src/lib/motor-precios/queries.ts` | `crearBibliotecaPrecio()` |
| `BibliotecaNuevaClient.tsx` · `BibliotecaHistoricoClient.tsx` | `fetchJson()` (mensaje legible si cuerpo vacío) |

**Commit:** `7afb506` — `fix(motor-precios): POST crear biblioteca_precio — corrige Unexpected end of JSON input`  
**Prod:** deploy CLI `--project rimec-report` → alias `https://rimec-report.vercel.app` · deployment `dpl_BfZLaHuTfSR3eEYYRTBKXupqUwfQ`
