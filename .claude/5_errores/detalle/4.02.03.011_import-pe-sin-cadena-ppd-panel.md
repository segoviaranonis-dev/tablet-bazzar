## Causa raíz (error de lógica — no repetir)

1. **No consultar Moria antes de importar** — cadena obligatoria documentada en `CHUSAR_STOCK_PRONTA_ENTREGA_RIMEC.md` + `ESTRATEGIA_HIEDRA_VENENOSA_PE.md` pero operadores/agentes ejecutaron solo CLI staging.
2. **Dos capas sin pipeline único:** `import_rimec_pronta_entrega_csv.py` → `stock_pronta_entrega_rimec` **≠** lectura Panel (`getStockProntaEntregaResumen` → **PPD**).
3. **Acumulación multi-batch:** importar batch nuevo **sin purgar** PPD batch anterior → Panel **suma** lotes (doble stock).
4. **UI hardcode `sdrm0831`** en `page.tsx` / API default batch — oculta batch real.
5. **Motor pilares PE incompleto** (`_provision_pilares` sin herencia género/estilo/LR) — viola `politicas-importacion-pilares.mdc` tercera vía operativa.
