# 4.02.02.003 · Report — Push main no actualiza rimec-report (proyecto Vercel duplicado)

**Capa:** Report · Deploy · Vercel  
**Estado:** ✅ **MITIGADO** 2026-07-02 · causa git-hook pendiente revisión DevOps  
**Relacionado:** [4.02.01.002](./4.02.01.002_biblioteca-post-json-vacio.md)

---

## Síntoma

- `git push origin main` con fix en GitHub (`7afb506`).
- Dashboard **rimec-report** sigue en commit anterior (`99f3fb3`, 29 jun).
- Funcionarios en `https://rimec-report.vercel.app` sin el fix.
- Un `vercel --prod` desde `report/` actualizó **`report-plum-one.vercel.app`** (proyecto **`report`**), no el alias operativo.

---

## Causa

Dos proyectos Vercel bajo la misma cuenta:

| Proyecto | URL prod | Origen típico |
|----------|----------|---------------|
| **rimec-report** | https://rimec-report.vercel.app | Git `main` (funcionarios) |
| **report** | https://report-plum-one.vercel.app | CLI local |

Deploy CLI sin `--project rimec-report` **no** mueve prod de funcionarios.

---

## Mitigación aplicada

```powershell
cd report
npx vercel --prod --yes --project rimec-report
```

Build **Ready** · alias `rimec-report.vercel.app` · `dpl_BfZLaHuTfSR3eEYYRTBKXupqUwfQ`.

---

## Pendiente DevOps

- Verificar webhook GitHub → proyecto **rimec-report** (push `main` debe disparar build).
- Evitar deploys prod Report sin flag `--project rimec-report` salvo orden explícita.
