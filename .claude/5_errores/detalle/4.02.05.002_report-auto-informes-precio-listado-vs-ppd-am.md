## Síntoma / intención peligrosa

El panel §7 **Listados de precios** (bibliotecas Motor) sugiere que el PDF usará el **precio vigente** del listado / catálogo RIMEC Web al generar el informe.

Eso **contradice** la estrategia **Alejandro Magno** y la certificación de precios CP/PE:

| Origen stock | Verdad de precio (unidad de dirección) | Prohibido |
|--------------|----------------------------------------|-----------|
| **Compra previa** (PP tránsito) | `pedido_proveedor_detalle.precio_lpn` (+ LPC tier) tras **vincular listado** al PP | Releer `precio_lista` / evento Motor en runtime Web/PDF |
| **Pronta entrega (SPE/DPE)** | LPN del import SDRM → PPD PE (`quincena_desc = Pronta entrega`) + reglas DPE/comercial | Re-aplicar biblioteca Motor arbitraria al armar el PDF |

RIMEC Web **ya** muestra el precio correcto porque lee **PPD / vistas** (`v_stock_rimec` MIG-176 · PE en `v_stock_pe_rimec`), no porque el PDF deba “volver a preguntar al Motor”.

---

## Por qué es error de arquitectura

1. **Dos orígenes de precio** en el mismo artículo = rotura de certificación (`4.02.03.022` · doctrina CP).  
2. El listado Motor es **unidad de mando** (ajustar estrategias). El PP/PPD es **unidad de dirección** (precio de venta congelado al vincular / importar).  
3. Un PDF de automatización que use “listado vigente” puede **divergir** del carrito, FI y Web en el mismo segundo.  
4. SPE/DPE: el CSV trae LPN; DPE segrega NORMAL/PROMO/LIQ — el PDF debe **segregar LPN vs LPC03** desde PPD, no inventar precio desde otra biblioteca.

Doctrina canónica: [CHUSAR_CERTIFICACION_PRECIOS_CP_RIMEC.md](../../2_modulos/2.3_report/proceso_importacion/CHUSAR_CERTIFICACION_PRECIOS_CP_RIMEC.md) (**2.3.1.7.5.3.8**) · [MAPA_PRECIOS_STOCK_PP.md](../../2_modulos/2.3_report/proceso_importacion/MAPA_PRECIOS_STOCK_PP.md) · Hiedra PE / import LPN.

## Regla para el generador PDF (automatización)

```
origen COMPRA_PREVIA  → precio = PPD.precio_lpn / tiers LPC del PP filtrado
origen PRONTA_ENTREGA → precio = PPD PE (LPN import) · tiers según DPE/política
PDF por marca+caso    → segregación rígida LPN ≠ LPC03 (misma lógica FI)
NUNCA                 → JOIN precio_lista “vigente” ni “precio Web recalculado”
```

§7 Listados **no** puede ser origen de LPN del PDF. Si se conserva, solo como filtro opcional de **caso/biblioteca de contexto** — nunca como motor de precio.

---

## Relación con hermanos siameses

Siameses = **mismas reglas de filtro/badge** Web ↔ AM.  
No autoriza **mismo precio recalculado** desde Motor: Web y AM ya consumen la **misma dirección** (PPD).
