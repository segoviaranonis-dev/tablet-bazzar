# 4.01.03.001 · RIMEC Web login — Bazzar VENDEDOR bloqueado en prod

**Clase:** 4.01 · RIMEC Web · Auth  
**Fecha:** 2026-07-07  
**Estado:** ✅ **RESUELTO** · prod `rimec-web.vercel.app`  
**Keyword:** Bug urgente!! · hotfix urgente

---

## Síntoma

Usuario tienda **BZZS** (San Martín adultos · compra RIMEC) no entraba en **RIMEC Web** producción:

- Mensaje: *«Los vendedores de tienda Bazzar no tienen acceso al catálogo web.»*
- HTTP **403** tras credenciales válidas (no 401).

Reclamo operativo: la tienda debe comprar en catálogo mayorista con cuenta **VENDEDOR** tienda (paridad **ATI**), ingresando código de cliente en carrito.

---

## Causa

1. **Código:** `rimec-web/lib/auth/roles.ts` — `puedeAccederRimecWeb` rechazaba `rol_id === 2 && categoria === VENDEDOR`.
2. **Matriz doc desactualizada** vs regla Director: cuentas **BZZS/BZZP** = compra tienda; **IVO** = gerente (ADMIN Report+Tablet).
3. **Prod** sin deploy del hotfix — local `:3001` ya OK mientras Vercel servía build anterior.

**Contraseña (no era bug auth):** canónica BD **`141592`** — no `1415192`.

---

## Fix

| Pieza | Cambio |
|-------|--------|
| `lib/auth/roles.ts` | VENDEDOR Bazzar permitido en catálogo (mismo nivel web que ATI) |
| `app/api/auth/login/route.ts` | Quitado mensaje hardcodeado Bazzar bloqueado |
| Git | commit `e380dd7` → `main` |
| Vercel prod | deploy `dpl_2ERKN7yrXBjj2k1tyeywRXY47ywN` · alias `rimec-web.vercel.app` |
