## Evidencia 2026-08-06 (falso alarma prod)

1. Push Documenta holding → rama **`moises-holding`** en `tablet-bazzar.git`.  
2. Vercel proyecto **tablet-bazzar** construyó **Preview** del tip holding (sin `app/` en raíz) → Error *Couldn't find pages or app*.  
3. Director leyó el log como fallo de rimec — **no lo era**.  
4. **Prod tablet** seguía READY (main · tip producto). **Prod rimec** `bcc476c` READY.

### Mitigación aplicada

Raíz holding `vercel.json`:

```json
{
  "git": {
    "deploymentEnabled": {
      "moises-holding": false
    }
  }
}
```

Push posterior a `moises-holding` **ya no** dispara build tablet.

### Lecciones

- Log Vercel con repo `tablet-bazzar` + branch `moises-holding` = holding, **no** rimec-web.  
- Deploy rimec = repo `rimec-web.git` / proyecto Vercel `rimec-web`.  
- Remote canónico de la raíz sigue **pendiente** (agenda fin de semana § abajo).
