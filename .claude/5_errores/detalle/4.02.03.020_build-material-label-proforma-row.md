# 4.02.03.020 · Build Vercel — `material_label` ausente en `ProformaRow`

**Estado:** ✅ **RESUELTO** 2026-07-23  
**App:** Report · deploy Vercel  
**Síntoma:** Build falla: `Property 'material_label' does not exist on type 'ProformaRow'` en `proforma-programado-engine.ts`  
**Commit fix:** `22faede` · agrega `material_label?: string` en `parse-proforma.ts`  
**Relacionado:** deploy cola import `75be90a`

---

## Causa

Commit `75be90a` incluyó uso de `r.material_label` en engine pero **no** el tipo en `parse-proforma.ts` remoto.

---

## Fix

Añadir al tipo `ProformaRow`:

```typescript
/** CP confecciones 638 — col J Descripción (BLUSA, CONJ FEM) para catálogo Web. */
material_label?: string;
```

**Regla deploy:** engine + parser **mismo commit** si se toca campo nuevo del Excel.
