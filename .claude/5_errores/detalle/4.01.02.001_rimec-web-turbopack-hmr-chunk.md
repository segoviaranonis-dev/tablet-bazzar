# 4.01.02.001 · RIMEC Web — Turbopack HMR chunk corrupto (dev local)

**Capa:** RIMEC Web · Next.js 16.2.4 (Turbopack) · puerto **3001**  
**Estado:** ✅ Hotfix conocido  
**Detectado:** 2026-07-05

## Síntoma

```
Runtime ChunkLoadError
Failed to load chunk /_next/static/chunks/%5Bturbopack%5D_browser_dev_hmr-client_hmr-client_ts_*.js
from module [turbopack]/browser/dev/hmr-client/hmr-client.ts [app-client]
Next.js version: 16.2.4 (Turbopack)
```

Tras reinicio brusco del dev, `.next` stale, pestaña con HMR viejo, o `build` + `dev` en paralelo.

**No confundir** con Report (`4.02.02.002`) — Report usa Webpack 15 en **3000**.

## Fix (PowerShell — `rimec-web/`)

1. Matar proceso en puerto **3001**
2. Borrar `.next` y `node_modules/.cache`
3. `npm run dev:clean` *(o `npm run dev` tras limpieza manual)*
4. Hard refresh navegador (Ctrl+F5) en `http://localhost:3001`

```powershell
Get-NetTCPConnection -LocalPort 3001 -ErrorAction SilentlyContinue |
  Select-Object -ExpandProperty OwningProcess -Unique |
  ForEach-Object { Stop-Process -Id $_ -Force -ErrorAction SilentlyContinue }
Remove-Item -Recurse -Force rimec-web\.next, rimec-web\node_modules\.cache -ErrorAction SilentlyContinue
Set-Location rimec-web; npm run dev:clean
```

## Regla agente

Verificar terminal `Ready in` + HTTP 200 en ruta afectada antes de cerrar turno.
